## 5. 数据源边界与未覆盖项

- 热门板块本机已验收，未发布线上。使用 README 现有 SSH 目标尝试只读验证，认证返回 Permission denied，未能验证部署服务器的资金源可用性；未更新远端代码、配置或数据库。
- 未完成完整交易日及跨交易日持续观察，不将本机一次成功视为长期可用性。来源未提供5日/10日起点和当日历史完成标志，前端分别说明起点未知、当日未确认最终值。
- 原始资金总额和过滤后的个股列表不同范围；不能对账为相等，也不将重叠概念合计为市场资金。

- 十年历史采取按股按需缓存，没有宣称全部 5,573 只股票均补齐十年；全市场历史仍含 450 个缺口批次、14 个失败批次，实际状态以页面为准。
- 本轮真实长历史重点抽样贵州茅台、官方指数抽样银行；其他股票、行业依赖相同校验路径，未全量逐条对源审计。
- 免费源不提供可靠正式历史停复牌/历史 ST/历史市值或自动北交所新旧代码映射。缺口不会据此改写为停牌；正式停牌计算通过合成数据回归。
- 来源仅提供最新权重，未给权重生效日期；页面明确“来源未提供”。本轮没有验证所有公司简介和主营业务文本。
- Tushare 代码有回归覆盖，但本轮未使用真实凭证验证权限或多年同步。Tushare 长历史由 CLI 导入，不在页面发起全市场多年同步。
- 自选和偏好仅当前浏览器保存，清除本地存储即丢失；不支持云端同步。
- 本次当日行情随本机网页服务运行，无需另设系统行情定时器。本次未部署线上版本；既有线上盘后任务见 README。
