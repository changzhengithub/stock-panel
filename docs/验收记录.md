## 1. 当前交付

- 默认全部股票；独立全市场代码/名称/拼音/首字母搜索；当前列表关键词明确取交集。
- 两级“行业指数权重前三”统一命名；原始前三匹配不递补、不重排名，权重日期与获取日期分别显示。
- 浏览器本地自选、最近查看、跨分页前后导航、多字段服务端升降序和 URL 恢复。
- 日周月 K 线、前复权/不复权、最长十年按需历史、缩放/平移/重置、图表偏好持久化。
- 区分正式停牌与未知缺口；指标计算历史与显示区间分开；更新失败保留旧图和旧基准。
- 行业/市场涨跌家数、有效覆盖，以及同日官方行业指数；缺失不冒充平盘，不以成分股均值代替指数。
- 需求、同步说明和 README 已统一；旧“人工代表股、仅一年、折线图、不含自选”的条款不再是当前基线。

## 5. 数据源边界与未覆盖项

- 十年历史采取按股按需缓存，没有宣称全部 5,573 只股票均补齐十年；全市场历史仍含 450 个缺口批次、14 个失败批次，实际状态以页面为准。
- 本轮真实长历史重点抽样贵州茅台、官方指数抽样银行；其他股票、行业依赖相同校验路径，未全量逐条对源审计。
- 免费源不提供可靠正式历史停复牌/历史 ST/历史市值或自动北交所新旧代码映射。缺口不会据此改写为停牌；正式停牌计算通过合成数据回归。
- 来源仅提供最新权重，未给权重生效日期；页面明确“来源未提供”。本轮没有验证所有公司简介和主营业务文本。
- Tushare 代码有回归覆盖，但本轮未使用真实凭证验证权限或多年同步。Tushare 长历史由 CLI 导入，不在页面发起全市场多年同步。
- 自选和偏好仅当前浏览器保存，清除本地存储即丢失；不支持云端同步。
- 未安装或启用系统定时任务；本机启动方式和定时运行条件见《数据同步说明》。
