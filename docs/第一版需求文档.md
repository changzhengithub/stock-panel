# A 股市场浏览看板需求文档

版本：V1.5 · 更新日期：2026-10-14 · 当前产品基线

本文件统一描述当前需求。实现、自动化测试、真实数据和浏览器验证分别记录在《验收记录》，数据源细则见《数据同步说明》。

## 1. 产品定位与范围

供个人认识行业、查找公司、查看免费当天行情与历史走势，覆盖沪深北当前上市 A 股。核心路径：找股票或浏览行业 → 筛选与比较 → 个股速览或详情 → 自选与连续浏览。

| 包含 | 不包含 |
| --- | --- |
| SW2021 一级、二级行业、东方财富概念板块和上市市场筛选 | 港美股、B 股、基金、债券 |
| 免费当日行情自动更新、全市场搜索、当前列表筛选、全市场排序 | 逐笔推送、分时盘口、交易下单 |
| 行业指数权重前三与完整行业股票；按数据源成分筛选概念股票 | 按主营业务自行推断概念归属 |
| 公司资料、行情指标、日周月 K 线、产业链图谱与有证据的业务分析 | AI 选股、技术策略、回测、深度财务分析 |
| 热门行业/概念资金排行、资金趋势、同源成分股资金 | 板块间真实资金转移、综合评分、交易所资金聚合 |
| 浏览器本地自选、最近查看、偏好记忆 | 账户体系、云端自选同步、价格提醒 |

行情必须免费，覆盖沪深北基础报价，获取当天实际行情；延迟可以接受。页面显示来源交易日期、时分秒、有效覆盖和数据来源。每个市场独立校验覆盖率，缺失字段明确留空；失败保留原始日期与旧数据并提示。

## 2. 页面与默认状态

- 主导航提供“市场浏览”“热门板块”和“产业链分析”；热门入口 `/hot-sectors`，板块详情 `/hot-sectors/:id`。
- `/market` 默认“市场 / 全部市场 / 全部行业 / 全部股票 / 默认排序”。全部股票是首屏入口。
- 浏览股票池统一排除 ST（含 *ST、S*ST）、退市及非当前上市股票。以当前简称、上市状态、已生效退市日期和最新已发布行情的 ST 标记判断；列表、搜索、自选/最近查看、行业数量、代表股、涨跌统计、详情和 K 线入口使用同一规则。普通停牌股票仍保留。
- 顶部提供全市场搜索与交易所市场选择；市场、自选为浏览集合。最近查看仅保留在顶部全市场搜索的空输入建议中。
- 桌面保持行业导航、股票列表、个股速览三栏；窄屏使用行业下拉与自然页面滚动。
- 选择一级行业可展开二级子类；一级、二级筛选分别按对应归属查询。未覆盖股票显示“未分类”或“未细分”，不能从股票库消失。
- 默认显示全部股票；“筛选当前列表”位于筛选行最左侧，“龙头股”按钮位于同排右侧“默认”排序按钮后面，点击后只改变股票范围。所有筛选共用同一张股票表，默认每页 50 条，支持 20/50/100 条。
- `/stocks/:id` 展示公司资料、行情、K 线、权重来源和上一只/下一只。返回时恢复来源列表的筛选、排序、集合和页码。

## 3. 搜索、筛选、排序和浏览集合

### 3.1 两种搜索职责

| 入口 | 范围与规则 |
| --- | --- |
| 顶部全市场搜索 | 代码、名称、拼音全拼和首字母；不受行业、交易所、权重名单、自选或当前列表关键词限制；选择后进入详情；空输入显示最近查看 |
| “筛选当前列表” | 在当前行业、市场、股票范围和浏览集合中按代码或名称取交集；明确标明作用范围 |

更改列表条件回第一页；条件保存在 URL，刷新和返回恢复。快速切换时取消旧请求或忽略迟到响应。权重筛选无结果时提示可能是当前条件无匹配或来源暂无有效权重名单。

### 3.2 排序

- 表格支持最新价、涨跌幅、成交额、总市值、换手率升降序；在服务端排序整个结果集后分页。
- 快捷涨跌入口命名“涨跌幅降序/升序”，不额外筛正负值，不把负收益称为上涨。
- 涨跌幅排序只包含当日有效交易行情；其余数值排序空值始终末尾，同值按代码及交易所稳定排序。
- 默认股票排序按代码及交易所；权重筛选的默认顺序按本级行业及原始指数名次。自选默认保存顺序；仍可叠加筛选和数值排序。
- 详情上一只/下一只遵循来源列表的完整排序，可跨分页；边界禁用，不循环。

### 3.3 自选和最近查看

支持列表、速览、详情添加或移除自选，最多 500 只；详情访问进入最近查看，最多 30 只，去重。被动选中的速览不计入最近查看。

数据保存在当前浏览器 localStorage，不上传服务器。相同浏览器多标签同步；存储失败明确提示。清除浏览器数据会清除这些记录，证券仍以服务端当前资料与行情显示。

## 4. 行业语义与市场概况

### 4.1 龙头股（行业指数权重前三）

- 采用 SW2021 本级行业指数公开成分的最新权重。一级和二级独立计算；不是人工代表股、市值前三、营收或市场份额龙头。
- 先确定源权重前三名，再校验本地上市状态和本级行业归属。匹配失败的名次缺席，不用第四名递补，也不重新编号。
- 权重接口须通过重复、正数和总和检查；没有公开权重的分类不生成名单。获取失败保留该行业上一份已验证的官方名单与原获取日期。
- 显示原始名次、权重、来源链接、权重日期、获取日期。来源未给权重日期时明确“来源未提供”，不能用获取日冒充权重生效日。
- 旧人工配置不进入运行路径。分类获取时间、分类来源最近变动日期、指数权重日期和行情交易日互相独立。

### 4.2 市场和行业概况

- 上涨、下跌、平盘家数按当前行业和市场排除 ST、退市后的浏览股票池计算，不受列表关键词、自选或权重范围限制，并显示有效数、总数、未参与数。
- 只有当日有效交易行情参与家数统计；缺失和正式停牌不当作平盘。
- 选中有官方指数的行业时，按需读取与行情同日的指数收盘及相对前一交易日的涨跌幅。标明“完整行业”，不随交易所子集过滤，不用成分股简单均值替代指数。
- 缺少同日或前一交易日指数数据时显示暂无，保留原因；加载与失败有界，不无限显示“读取中”。

## 5. 行情、详情和历史图表

### 5.1 行情字段

列表和摘要使用同一批免费行情的最新未复权价格；金额统一元，按万/亿展示；涨跌幅是百分数。红涨绿跌，平盘中性，同时保留数字正负号；缺失为“—”，不与零混淆。

详情包括代码、名称、全称、行业、板块、上市日期、简介和主营业务，以及最新价、昨收、今开、最高、最低、成交量、涨跌幅、成交额、总市值、流通市值、换手率、PE、PB、总股本和流通股本。估值字段保留来源口径；不通过市值除价格等方式倒推缺失股本。没有资料明确提示。

正式停牌只能来自正式状态源；无行情或零成交不推断停牌。免费模式按当前名称识别并排除 ST，不推断历史 ST。

### 5.2 K 线与指标

| 能力 | 规则 |
| --- | --- |
| 周期 | 日 K、自然周 K、自然月 K；周/月按第一开盘、最高、最低、末次收盘汇总，成交量合计 |
| 复权 | 前复权和不复权可切换；摘要始终实际价；前复权基准固定到该历史批次已发布行情日 |
| 显示区间 | 近一个月、三个月、一年、三年、五年、十年 |
| 计算历史 | 与显示区间分开：普通日线一年，周线至少五年，月线十年；选择三年请求五年、五年或十年请求十年 |
| 均线和副图 | MA5/10/20/60、成交量及均量线、MACD(12,26,9)、RSI(14)；按所选周期收盘计算，先预热再显示 |
| 浏览操作 | 滚轮缩放、拖动平移、底部区间滑块、恢复默认视图；缩放同时联动主副图和可见价格范围 |
| 偏好 | 周期、区间、复权方式和副图选择保存在本地，刷新和换股保持 |
| 速览 | 简化图表，隐藏坐标轴；详情保留完整坐标与图表操作 |

切换月线且原区间很短时默认展示近五年。指标历史不足时显示空值或禁用对应副图，说明原因，不显示伪造的零值。当前周/月按已发生交易展示，提示中注明实际截止日期，不代表整周/月已结束。

已确认停牌日从有效交易序列跳过，不把整周/月作废，不重置连续有效记录的指标。未知交易日缺口显示断点；包含未知价格缺口的周/月不绘制 OHLC，指标重新预热；成交量缺失仅影响成交量与均量线。请求起点截断的首个周/月不作为完整周期。上市时间和数据源限制按实际可用历史展示。

### 5.3 异常与恢复

- 首次加载、空结果、数据缺口、同步中和请求失败分别表达。
- 同一股票同一复权口径刷新失败保留已有可用图表和原基准日期，提示陈旧/失败；不能把旧图标成新基准。
- 切换股票或复权口径时清除不适用的图，防止旧股/旧口径短暂冒充新结果。
- 历史缓存按股票事务写入，扩展历史不会被下一次短区间同步截短。
- 免费历史按需后台获取；有界轮询和错误退避，失败提供刷新入口。Tushare 长历史通过同步命令导入，未导入时显示缺口。

## 6. 数据与运行要求

默认免费公开数据，无需 Token；Tushare 为可选。Vue 3 + TypeScript + Element Plus + ECharts，FastAPI + SQLAlchemy + Alembic，SQLite，本机运行。

当日免费行情按沪、深、北三个市场分别校验，不低于 95% 有效覆盖才替换整批缓存；每股保留实际交易日期、时间，缺股不填充昨日报价。服务启动自动抓取，交易窗口每轮完成后间隔约两分钟，页面可见时每三十秒刷新，切回页面立即刷新。自动更新须静默完成，保留已显示数据、滚动位置、选中股票和图表缩放；不显示变淡、重新加载或清空统计的痕迹，数据未变时不重绘。收盘后的日线快照仍独立校验并发布，不用盘中数据覆盖历史或复权因子。历史原始和后复权价格成对取同源，统一基准归一化；原始 OHLC 独立保存供不复权显示。长历史按年分段或向前分页，检查日期集合和交易日历。

默认 bootstrap 处理首批 100 只近一年历史，sync 处理 20 只，backfill 可补全市场或指定股票/日期。日历、来源、完整性、任务状态与每股历史分别记录。每日 18:30 同步配置可由用户安装，应用启动可补同步；电脑休眠/关机不保证准时执行。

迁移前使用 SQLite 一致性备份；不删除或覆盖用户历史。密钥仅后端读取，不写入前端和日志。实际接口、参数、单位与备份步骤见《数据同步说明》。

## 7. 热门板块与资金流向

- 默认“概念 / 今日 / 全部排行 / 主力净流入降序 / 每页 20 条”；可切换东方财富行业分类、5日、10日，按名称或来源代码检索全部有效板块。资金流入/流出快捷入口分别仅保留正值/负值并按净额降序/升序；默认排行包含零和负值。
- 服务端全量排序后分页，支持净额、净占比、同周期涨跌幅升降序；空值末尾，同值按代码稳定排序。每页 20/50/100 条。概览按当前类型和周期完整批次计算，不随关键词和分页变化，与排行使用同一批次。
- 板块以来源、类型及来源代码确定身份。排行、历史、成分资金采用东方财富同源数据，不按名称套用 SW2021 或通达信成员；不限制为市场页精选概念，不提供交易所资金筛选。
- 页面增加全批次双向主力净额图：以零轴区分红色向右净流入和绿色向左净流出，统一金额刻度，默认两侧各前 5 个，可切换各前 10 个。随板块类型与资金周期切换，不随下方关键词、方向、排序或分页变化；点击条形联动板块详情，支持键盘选择。
- 桌面排行与详情并列；窄屏点击板块进入详情。板块详情包含所选周期净额/净占比/涨跌幅、同周期最大资金股、每日资金趋势、当日订单规模拆分、同源成分股资金表。最大资金股不等同现有行业“龙头股”。
- 资金历史提供近 20/60 交易日视图，按实际可用范围展示；缺口为空，不补零。当日历史点标注“未确认最终值”，不写入已过交易日的持久历史；下次取数时已过交易日再保存。来源没有最终完成标记时不凭 15:00 的电脑时间宣称完成。
- 金额统一元、界面按万/亿展示，数字保留正负号，缺失为“—”。不同周期使用来源对应字段，不平均每日占比、不相加每日涨跌幅。5日/10日来源未提供区间起点时明确说明，不猜日期。
- 板块总额保留来源完整口径，成分股列表沿用本站 ST/退市过滤并保留普通停牌，分别统计被过滤、未匹配和资金缺失。固定说明两者金额可能不相等。个股代码/市场与已验证别名关联本地 ID，不按简称猜测。
- 来源交易日期/时间与获取时间分别展示；排行、每日历史、当日拆分和成分资金各有状态，不混批宣称同时更新。源日期缺失或有效记录日期冲突时拒绝发布。
- 自动采集独立于行情任务，当前排行缓存约五分钟更新，页面可见时每三十秒读本地缓存；历史约三十分钟、成分资金约五分钟按需刷新。无缓存、后台获取、无匹配、更新失败分别表达。失败保留旧数据、原日期并退避五分钟；静默刷新保留滚动、选中板块和图表区间。
- 筛选、分页和选板块保存 URL；进入股票详情后“返回热门板块”恢复原条件，热门来源隐藏市场顺序前后导航，保留自选能力。市场来源原有导航保持正常。
- 资金流向表达来源的成交分类指标，不代表真实机构账户进出；概念重叠不合计为全市场资金，不画声称板块间实际转移的流向图。

## 8. 产业链分析

- 入口 `/industry-chains`，分析 `/industry-chains/:id`，同节点比较 `/industry-chains/:id/compare`。提供三条资料专题及 SW2021 全部 31 个一级/134 个二级行业基线。基线不代表全量研究已核验；近似词、分类关系建议和请求失败分别表达。
- 名称、别名、代码和拼音搜索；来自行业页通过显式映射关联，不按名称套用 SW2021 或概念成员。产业链、节点和关系使用独立身份。
- 行业速读、需求与观察变量、主链/分支/循环图、简明/完整切换、节点列表与关系解释。桌面图谱加详情，窄屏默认节点列表；节点和关系可键盘进入。
- 每条影响说明变化、机制、成立条件、时间特征、观察指标与依据，区分事实和分析判断；经营影响不直接推断股价，也不以资金流向代替因果依据。
- 公司—节点记录实际产品、经营主体、参与方式、阶段及证据；公司可跨节点，全链按证券身份去重。股池、数量和比较统一排除 ST/退市，普通停牌保留。资料核验、业务词匹配和分类候选分别标注。不能定位节点时单列候选公司，不由分类推导经营事实。
- 节点龙头按产品、地域、期间、指标和依据认定，与市场页指数权重前三独立；无可靠数据时仅标代表企业或缺失，不强制前三和递补。
- 财务保留报告期、主体、业务口径、币种及来源。收入占比必须核对分子分母；同节点 2～4 家比较只对共同报告期与同口径数据给出可比结论，不足则显示原因、不排名。行情采用现有 QuoteStamp，独立标时间。
- 股票表支持当前节点/全链、关键词、业务关联状态、参与方式、阶段、龙头类型、排序与 20/50/100 分页；全量排序再分页，空值末尾。节点、视图、筛选、版本写 URL；返回恢复图谱、筛选和页面位置。
- 链/节点收藏保存在本地浏览器，股票复用自选；失效节点不自动替换。产业链来源的个股隐藏市场顺序前后按钮，返回站内白名单路径；现有市场/热门来源保留。
- 内容包走校验、显式核验记录、事务发布；公开 API 只读且仅返回 published，阅读固定 revision。更新失败保留旧版，纠错发布新版本；资料与行情不按同一更新时间宣称最新。
- 全股票池业务和最近年度/半年度分部资料通过公开数据商取得，保存来源快照与采集覆盖；源缺失和未核验分开，数据商财务禁止自动排名。当前专题由 Codex 核对官方/协会公开资料并记录身份；全文访问受限的来源标明检索核验，独立人工复核仍待完成。缺少分部财务、可靠排名和未收录终端公司均明确说明。
- 维护使用 `validate-chain`、`import-chain`、`review-chain`、`publish-chain`、`doctor-chain`；全行业使用 `collect-business`、`build-industry-chains`、`publish-chain-batch`，启动不自动联网搜报告或调用 AI。后续 AI 草稿、情景推演与事件跟踪不属于当前首版。
