# 数据同步与运行说明

## 浏览股票池

所有浏览接口统一排除当前简称含 ST（不区分大小写，覆盖 *ST、S*ST）或“退”的股票、上市状态非 L 的股票、退市日期已生效的股票，以及最新已发布行情中明确标为 ST 的股票。普通停牌和缺失行情不会被当作退市。列表与分页、搜索、自选/最近查看、行业计数、代表股、涨跌统计及详情/K 线入口采用相同口径。

源资料与历史行情保留供同步校验；浏览时实时应用筛选，无需重新下载行情，后续同步也持续生效。ST 状态解除且最新资料与已发布标记均符合条件后可恢复展示。同步覆盖校验及发布记录中的行情/市值缺失数量仍按原始源股票池统计，不因浏览筛选改变。官方行业指数保留原始指数口径。

## 免费模式（默认，无需 Token）

`DATA_PROVIDER=free`；依赖 AKShare 1.19.1，版本由 uv.lock 锁定。

| 数据 | 主通道 | 备用与处理 |
| --- | --- | --- |
| 股票名单、上市日期 | AKShare 上交所主板/科创板、深交所 A 股列表、北交所列表 | 任一市场失败则保留原资料，不缩减市场范围 |
| 行业 | index_realtime_sw 一级行业 + index_component_sw；SW2021 官方网站的个股分类历史文件 | 校验 31 个一级、134 个二级行业；当前二级归属与一级成分核对，至少覆盖 99% 当前上市名单；缺失归“未细分”，验证失败保留原资料 |
| 日历 | tool_trade_date_hist_sina | 必须覆盖目标日期，三地共用公开交易日历；不按工作日推测 |
| 最新行情 | 东方财富 clist，全分页且校验 total | 腾讯 qt.gtimg.cn，按交易所名单每批 80 只；存储实际通道来源 |
| 历史价格 | 东方财富原始和后复权日线 | 腾讯 newfqkline 原始和后复权日线；成对切换，不混用两源因子 |
| 公司资料 | AKShare stock_profile_cninfo / 巨潮 | 首次打开详情后台补取，可选资料失败保持空值 |
| 概念板块 | 通达信公开行情服务器 `block_gn.dat` | 一次下载全量板块文件，校验成分数量、代码和本地股票匹配；达到 400 只文件上限的板块不发布可能截断的名单 |

东方财富成交额、市值原生为元。腾讯字段 57 成交额为万元，乘 10000；字段 45 总市值为亿元，乘 100000000，因此腾讯市值精度低于元，页面以亿元展示。行情使用源时间戳，收盘后 15:30 起允许读取当日快照；定时仍为 18:30。不会把今日快照写成昨日数据。

AKShare 内部的 SW2021 函数使用其自带的证书校验策略（当前版本请求 verify=False）。官方分类文件优先走 AKShare；若仅遇到 SW2021 数据站点证书链异常，会在隔离子进程内对固定的公开 Excel 地址重试，并校验文件格式、条数、代码、日期、层级及一级成分一致性。该备用请求不发送凭证或私人数据，不能作为密码学意义的来源认证。其他 HTTP 通道保持默认 TLS 校验。

### SW2021 行业分类与时效

- `config/sw2021-l2.json` 固定 SW2021 二级分类代码、名称与一级父级；个股归属每次元数据同步从 SW2021 官方网站分类历史文件取最新生效记录。二级指数实时列表只有 124 项，不能替代 134 类完整分类字典。
- 同步先验证完整股票名单、分类历史条数、代码和日期，要求至少 99% 当前上市股票匹配；已同时出现在一级成分中的股票还须父级一致。任何冲突或未知二级代码会中止本轮资料更新，保留上次有效归属。
- 行业归属与行情是两种独立时效：`industry_synced_at` 是本机最近成功获取分类文件的时间，`industry_source_updated_at` 是文件记录的最近更新日期；后者不会每天变化。行情以 `trade_date` 为准。页面每 30 秒读取本地数据状态，但不会将轮询显示为实时上游更新。
- 市场页在一级行业下展开二级子类；点击任一分类可切换其全部股票与该层级 SW2021 行业指数指数权重前三。一级与二级各取本级指数权重前三，不继承父级名单。股票缺少 SW2021 二级归属时归入“未细分”，不推断其细分行业。

### 免费快照与完整性

概念成分使用通达信公开服务器的 `block_gn.dat`。每次同步整份文件，要求至少 200 个概念、名称和成分代码无重复、成分数量一致、每个可发布板块至少 80% 成分与本地当前上市 A 股匹配。源文件对单板块最多列出 400 只；恰好达到 400 只的板块标记为可能截断，不把它的名单发布为完整成分。概念数据在校验后单事务更新；取数或校验失败时保留已发布名单。`fetched_at` 是本机获取时间，源文件没有提供成分生效日期，不能据此声称成分是当日更新。通达信与东方财富的概念名称可能相同，浏览接口优先显示已成功同步的通达信名单；现存东方财富有效名单仍可作为补充。

- 必须完整获取股票名单与行情分页。以当前上市日期和已知交易日计算股票范围；有同日、15:00 后源时间戳、正价格、有效涨跌幅和正成交额才纳入榜单。零成交不推断停牌。
- 免费模式允许有效覆盖不低于 95% 的行情快照，缺失股票显示为空并统计数量；不称为完整交易日。低于 95%、网络失败、分页截断均保留上次快照。这个门槛用于拦截大规模接口异常，不代表数据质量承诺。
- 所有行情在一个事务中替换，列表不拼接不同交易日。市值缺失单独计数。ST 根据当前名称从浏览股票池排除，不推断历史 ST。
- 免费模式不提供历史市值回填、正式停复牌状态，也不自动生成北交所新旧代码映射。当前新代码可以直接获取源提供的历史；发现与现存旧代码同名的新代码但无已验证别名时中止资料更新，不能靠名称自动合并。
- 元数据成功结果按北京时间日期缓存在 data/free-cache，失败不缓存；网络有限重试，AKShare 单次子进程超时 90 秒。CLI 使用单任务锁。

### 历史缓存与复权

历史保存到 history_bars / history_imports，与 publications 分开。每只股票按请求区间（最多十年）获取原始日线和后复权日线，用 `后复权当日价格 / 后复权基准日价格 × 基准日原始收盘价` 归一化，形成基准日为已发布行情日期的前复权展示价格。源价格存在舍入，展示保留 4 位小数；各显示区间共用该股票历史批次及其基准；未复权 OHLC 独立保存，不反推。

- 东方财富历史按自然年分段；腾讯首批取最近 640 条（日内可能 641 条），再按最早日期向前分页，去重并检查分页推进，最多 12 页。首批不带结束日期以避免遗漏当前交易日。源基准日原始价必须与行情快照一致（允许 0.011 元舍入误差）。
- 日期、价格、源股票代码、原始和后复权日期集合校验通过后，单股票事务替换历史；失败保留上次历史批次及其基准，记录错误。
- 交易日缺口明确返回 null，不补零、不推断停牌；无基准日价格时不生成复权图。免费源没有正式停牌解释，因此存在缺口的股票不计入完整历史。
- bootstrap 优先处理 100 只，sync 处理 20 只，backfill 默认处理全市场未完成股票；支持 --history-limit、--codes、--force。已完成或已记录部分缺口的同基准批次默认跳过，修复缺口用 --force。
- 股票详情和速览按需补取：日线常规一年、周线至少五年、月线十年，显示区间与计算历史分离。已扩展历史不被日常一年同步截短。每 3 秒轮询，最多 60 次后显示后台处理中；历史错误 5 分钟内不自动重试，可用 CLI 强制补齐。切换股票或复权方式清除不适用图表；同口径刷新失败保留原可用历史与原基准，并提示失败。日历准备阶段失败也记录错误。
- data-status.history.unit=stock 时，expected_days / published_days 两个兼容字段实际表示应导入/完整导入股票数；trading_day 时表示原 Tushare 按日进度。前端依据 unit 显示单位，不混淆。

官方接口参考：[AKShare 股票](https://akshare.akfamily.xyz/data/stock/stock.html)、[AKShare SW2021 行业指数](https://akshare.akfamily.xyz/data/index/index.html)、[腾讯日线适配源码](https://github.com/akfamily/akshare/blob/main/akshare/stock_feature/stock_hist_tx.py)。

## Tushare 严格逐日发布与失败处理

1. 先完整获取股票、代码映射、SW2021 行业、成分及日历，完成必要校验后更新基础资料。
2. 每个交易日按全市场批量请求日线、指标、因子和停复牌，分页检测重复返回，拒绝明显截断结果。
3. 按当前股票的上市日期与交易所日历确定应有记录集合；当前未收录的退市股票不属于首版历史覆盖目标。
4. 有有效行情的股票必须有收盘价、涨跌幅、成交额、市值和正数复权因子。没有日线时，只接受正式全天停牌记录作为解释。
5. 未解释的缺失导致当天失败，记录缺失股票；不把部分新结果覆盖到已发布交易日。
6. 当天校验通过后，在同一事务中更新行情、因子、发布记录和日期完成状态。
7. 每个日期独立处理；一般数据错误记录后继续其他日期，权限或额度错误停止本轮，避免无意义请求。
8. 重跑默认跳过已发布日期，`--force` 才会重新抓取。失败刷新不影响此前已发布结果。

全市场榜单使用同一个最新已发布日期，不拼接不同股票的最新价格。停牌股票没有当日价格时显示“—”，不把旧价格冒充当日价格。

历史走势只使用已发布日期，缺口保留为断点；缺少基准日因子时不生成误导性的复权图。股票资料、指数权重获取日期和行情日期分别记录。

## SW2021 指数权重前三

`sync` 和 `bootstrap` 在行情快照发布后读取 SW2021 行业指数成分股的“最新权重”，一级、二级各先按源权重确定前三名，再匹配本地股票，未匹配名次不递补且不重新编号；也可独立运行 `sync-leaders`。接口通过 AKShare 读取 SW2021 官方网站公开数据，校验成分唯一性、正权重及权重合计约为 100%，再核对本地当前上市状态和对应层级的行业归属。名单中展示原始指数权重名次、比例、权重日期、获取日期和 SW2021 行业指数详情链接。来源未提供权重日期时存 NULL，并显示“来源未提供”，不能把获取日当成权重生效日。

SW2021 二级分类字典有 134 类，而当前发布权重的二级指数只有 124 个；没有公开指数权重或权重校验失败的类别不生成名单。单个行业获取失败时保留该行业上一份已验证的官方权重名单，并保留其原获取日期；旧人工样本不会作为备用名单。指数权重是可复核的排序口径，不等同于公司营收、市占率或投资评级。旧的 `config/representatives.json` 和 `config/representatives_l2.json` 不再参与同步或网页展示。

## 行业概况与官方指数

`/api/industry-summary` 的涨跌家数基于当前行业和市场排除 ST、退市后的浏览股票池，只计同日有效交易行情；不受关键词、权重范围、自选或最近查看限制。有效数、总数和未参与数同时返回。

有官方指数的行业按需使用 `index_hist_sw` 读取日线，验证代码、日期唯一性、同日及前一交易日收盘，然后计算指数涨跌幅并缓存在 `industry_index_quotes`。指数表示完整行业，不随市场子集变化；不以成分股平均值替代。获取失败保存原因、5 分钟退避，有效旧记录不被失败覆盖；不显示不同日期指数冒充当前值。前端最多轮询 60 次。

## macOS 定时运行

项目只提供配置生成器，不自动安装系统任务。`launchd` 的日历触发使用电脑系统时区；以下 18:30 配置要求系统时区为 Asia/Shanghai。环境变量 TZ 只设置 Python 进程时区，不改变 launchd 的时钟。

先在项目根目录生成配置并检查实际路径：

```bash
backend/.venv/bin/python scripts/render_launchd.py > data/local.stock-panel.sync.plist
plutil -lint data/local.stock-panel.sync.plist
```

需要启用时，由用户执行：

```bash
mkdir -p "$HOME/Library/LaunchAgents"
cp data/local.stock-panel.sync.plist "$HOME/Library/LaunchAgents/local.stock-panel.sync.plist"
launchctl bootstrap "gui/$(id -u)" "$HOME/Library/LaunchAgents/local.stock-panel.sync.plist"
```

停用：

```bash
launchctl bootout "gui/$(id -u)" "$HOME/Library/LaunchAgents/local.stock-panel.sync.plist"
```

输出位于 `data/sync.log` 和 `data/sync-error.log`。电脑休眠、关机或任务未启用时不能保证准时同步；下一次应用启动会检查并补齐。定时任务与启动补同步共用进程锁，不并发写入。

## 备份与恢复

使用 README 中的 backup 命令生成一致性备份，禁止直接复制正在写入的数据库文件。恢复时先退出应用及同步任务，再验证备份：

```bash
sqlite3 data/backups/market-20261009.sqlite3 'PRAGMA integrity_check;'
```

验证应返回 `ok`。保留现有数据库及可能的 WAL/SHM 文件作为一个备份集合，然后将已验证备份复制到一个新的文件路径，并在 `.env` 中把 STOCK_DB_PATH 指向该路径。这样无需覆盖或删除现有数据。重新启动会检查数据库版本。

## 接口约定

- `/api/industries?level=1|2`：返回对应层级、父级与当前上市股票数量；二级同步完成前返回空列表。
- `/api/concepts`：返回东方财富概念目录、当前市场可浏览成分数量、来源、成分获取时间和最近错误；未成功同步成分的概念保留“待同步”状态。
- `/api/stocks`：过滤条件取交集；`industry_level=1|2` 决定 `industry_id` 的层级，`concept_id` 按独立的多对多成分筛选；page 从 1 开始，page_size 最大 100。概念筛选不支持行业指数权重前三。
- `/api/industry-summary` 接收 `concept_id` 后统计概念成分的同日有效行情，不读取或展示申万行业指数。
- `scope=all|representatives`，默认 all；`sort=default`，或 `pct|market_cap|close|amount|turnover` 加 `_asc|_desc`。
- `/api/search?keyword=...`：全市场代码、名称、拼音/首字母，最多 20 项；不接收列表范围过滤。
- `codes` 为自选/最近查看的逗号分隔 ts_code；空字符串表示空集合，默认排序遵循传入顺序。`neighbor_of` 返回当前全部结果中的前后股票、位置和总数，独立于分页。
- `group_by=industry` 仅允许代表股默认排序；分页单位为行业，组内股票不截断。
- 股票表格分页默认 50；前端允许 20、50、100。行业分组每页 8 组。
- 涨幅榜按降序、跌幅榜按升序，不额外过滤正负值；同值按代码和交易所稳定排序。
- 金额 API 单位为元，涨跌幅是百分数，缺失值为 null。
- 无已发布行情返回可解释的空值和状态，不生成样例行情。
- `prices?range=1m|3m|1y|3y|5y|10y&adjustment=qfq|none` 返回所选口径 OHLC、成交量、基准日、历史起点、pending/stale、缺失日期和完整性状态；点状态区分 trading/suspended/missing。
- 正式停牌日不计入有效 K 线序列；未知缺口中断指标并使所在周/月 OHLC 无效，缺成交量只影响量图。
- 自选（500 只）、最近查看（30 只）与图表偏好只存浏览器 localStorage。
- `/api/data-status` 分别返回最新行情和近一年历史完整性；不是单一的“成功/失败”标志。

## 长历史与升级

默认批处理仍只请求一年，长历史可从详情按需获取，或指定日期：

```bash
backend/.venv/bin/python scripts/run.py backfill --codes 600519.SH --start 20161009 --end 20261009
```

免费 CLI 最多 3660 天。Tushare 仍通过逐日同步填充所需年份，不由页面自动发起多年全市场同步。前复权需基准因子，不复权读取原始 OHLC，无需因子。

迁移 0008 为历史新增原始开高低价、为两级权重记录新增可空权重日期，并增加官方行业指数日线缓存。旧行情和历史价格保留；旧缓存无原始 OHLC 时不复权按需重取，不能用复权价格伪装。迁移命令：`PYTHONPATH=backend backend/.venv/bin/python -m app.cli migrate`。
